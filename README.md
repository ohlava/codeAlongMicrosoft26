Command to copy List without data (only columns) 

eg: ./Copy-SharePointLists.ps1 -SourceSiteUrl "https://volkswagengroup.sharepoint.com/sites/Project03" -TargetSiteUrl "https://volkswagengroup.sharepoint.com/sites/TESTC" -CopyValues no -ClientId XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX

Command to copy List with data (columns + items data) 

eg: ./Copy-SharePointLists.ps1 -SourceSiteUrl "https://volkswagengroup.sharepoint.com/sites/Project03" -TargetSiteUrl "https://volkswagengroup.sharepoint.com/sites/TESTC" -CopyValues yes -ClientId XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX

Command to copy Events without data (only columns) 

eg: ./Copy-SharePointEvents.ps1 -SourceSiteUrl "https://volkswagengroup.sharepoint.com/sites/Project03" -TargetSiteUrl "https://volkswagengroup.sharepoint.com/sites/TESTC" -CopyValues no -ClientId XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX

Command to copy Events with data (columns + items data) 

eg: ./Copy-SharePointEvents.ps1 -SourceSiteUrl "https://volkswagengroup.sharepoint.com/sites/Project03" -TargetSiteUrl "https://volkswagengroup.sharepoint.com/sites/TESTC" -CopyValues yes -ClientId XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX
