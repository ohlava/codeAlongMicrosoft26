Command to copy without data (only columns) 

eg: ./Copy-SharePointLists.ps1 -SourceSiteUrl "https://volkswagengroup.sharepoint.com/sites/Project03" -TargetSiteUrl "https://volkswagengroup.sharepoint.com/sites/TESTC" -CopyValues no

Command to copy with data (columns + items data) 

eg: ./Copy-SharePointLists.ps1 -SourceSiteUrl "https://volkswagengroup.sharepoint.com/sites/Project03" -TargetSiteUrl "https://volkswagengroup.sharepoint.com/sites/TESTC" -CopyValues yes
